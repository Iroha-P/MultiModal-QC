Traceable Pipeline

可解释流程

Pipeline 将一次质检拆成感知、检测、决策、报告四个步骤，展示模型结论从哪里来、如何被记录。

01

Perceive

读取图像或视频帧，整理视觉上下文。

02

Detect

输出缺陷类型、位置和置信信息。

03

Decide

结合阈值、场景规则和历史记录形成结论。

04

Report

生成中文说明、处置建议和导出字段。
